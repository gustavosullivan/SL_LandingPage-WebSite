# Funerária São Luiz — Landing Page

Landing page comercial da **Funerária São Luiz** (Passo Fundo/RS), otimizada para conversão e SEO local.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Schema.org (`FuneralHome` + `FAQPage`)

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Produção

```bash
npm run build
npm start
```

## SEO / ranking local

Além do site, para competir no Google Maps e nas buscas locais:

1. Confirmar e completar o **Google Business Profile**
2. Pedir avaliações reais de famílias atendidas
3. Publicar o domínio definitivo em `site.url` (hoje placeholder)
4. Enviar o sitemap no Google Search Console
5. Manter NAP consistente (nome, endereço, telefone) em diretórios
