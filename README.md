# Funerária São Luiz — Landing Page

Landing comercial da **Funerária São Luiz** (Passo Fundo/RS), com planos oficiais, cremação e cremação pet.

## Contato oficial

- **Endereço:** R. Teixeira Soares, 1118 — Centro, Passo Fundo/RS — CEP 99010-080
- **Horário:** Aberto 24h
- **Telefone:** (54) 3312-2688
- **Site:** [www.lucianocogo.com.br](https://www.lucianocogo.com.br)

## Planos e serviços no site

- **São Luiz Prev** — parcelas de 12x a 60x
- **São Luiz Plus** — parcelas de 12x a 60x
- **Cremação imediata** — à vista e parcelado + restos/ossada
- **Cremação Pet** — até 30 kg, acima de 30 kg e coletiva

Dados editáveis em `src/lib/site.ts`. Materiais de referência em `public/brand/`.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abre em **http://localhost:3010** (porta fixa para não conflitar com a SN250 na 3000).

## Produção

```bash
npm run build
npm start
```
